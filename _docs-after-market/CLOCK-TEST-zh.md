# 时钟测试说明（发给参加测试的玩家）

> 这版 WestPlay 的时钟跟游戏时间**应该**完全一致。但我们怀疑某些情况下会差一个小时，
> 所以加了一段诊断记录，想请你帮忙确认。

## 测试方法

1. 正常玩，注意看 **WestPlay 侧栏左上角的时间** 和 **游戏自己的时钟**（卡车仪表盘或路线顾问上的时间）
2. 如果两个时间不一样，马上记下：
   - 你**在哪个国家/城市**（地图上看得到）
   - **游戏显示几点**、**WestPlay 显示几点**（比如"游戏 14:05、WestPlay 13:05"）
3. **先不要关 WestPlay**，把下面这个文件发给我：
   ```
   文档\WestPlay\logs\app.log
   ```
4. 告诉我上面记的国家和时间，就这些。

## 为什么不能先关 WestPlay

这个日志**每次启动都会清空重写**。如果你先关了 WestPlay 再发，看到问题那次的记录就没了。

## 日志里我要看的那行

每次你经过一个新的国家/时区，日志会写一行，长这样：

```
page: clock country 23 zone 180 shift 60 on true at 13:05
```

意思是：识别到国家 23、时区 +180 分钟、WestPlay 的时钟比游戏基础时间快 60 分钟、
游戏里的"时区"选项是开着的、当时 WestPlay 显示 13:05。

配合你说的"游戏 14:05"，我就能判断是三种情况里的哪一种：
- 国家没认出来（网格缺失）
- 游戏自己按季节调整了（夏令时）
- 地图模组导致国家判断错误

## 如果不想参与

这行诊断记录只写日志，不影响游戏、不影响性能（每次换国家才写一行），忽略它也行。
