# 更新日志 · 2026-11-03

一页看完这一天新加的东西。桌面程序是 `D:\WestPlay\westplay.exe`，游戏插件没动。

## 一、新加的

1. **抖音**（首页新槽位）：装的就是抖音自己的网页，短视频在车里能刷；登录一次就记住。卡片上会有这一条的标题、作者和
   封面（页面自己不给封面时，取视频当前那一帧）。
2. **酷狗音乐**（首页新槽位）：酷狗的网页版，听歌、排行榜、歌单都在里面。它接进了车机的一整套：首页的正在播放卡片、
   大歌词页、快捷键和卡片上的切歌（上一首/下一首/播放暂停）、页面顶栏的歌名，用的都是它自己播放条上的信息。
3. **到终点后的附近推荐**：导航到最后 1 公里停下（或刚交完货），地图右下角会冒出一个小卡片，按你当下的状态推荐一个
   最近的地方——油少了推加油站、车该修了推维修站、快强制休息了推停车/酒店、没任务推货场。点一下就直接导航过去，
   卡片可以收起；同一条路推荐的就停在这儿时，会列出附近 10 公里内所有同类地点。
4. **顶部那条提示会轮播了**：每 3 秒换一条——休息倒计时、油量（「油量 412 升，剩余行驶里程 780 公里」）、限速和车速、
   交货还剩多久。倒车时自动让开。（磨损那一条按你的要求去掉了；后来只留休息和油量两句，见下面。）
5. **倒车画面能选视角了**：倒车页右上角的齿轮里有 5 种——车尾 + 车顶并排（默认）、后置视角、俯视视角、车尾为主车顶
   小窗、车顶为主车尾小窗。选一次记住，下次倒车还是它。

## 二、这一版之后又改的

- **酷狗页面不再透出车机原来的画面**：页面自己的底色没铺到的地方，现在一律补上底色；它那套定宽布局也会被缩进屏幕里，
  不再把右边裁掉。
- **抖音卡片的封面和标题**：推荐页原来只报站点自己的名字，现在读这一条的文案，封面取视频画面。
- **退出确认**：说明改成「确认后，WestPlay 程序将会关闭。」（英文、土耳其文、繁体一起改了；其余语种还是原句。）
- 轮播那条提示的宽度跟着文字走，不再出现截一半的省略号；浅色壁纸下是深字浅底。
- 推荐卡片不会压住地图右下角的指南针和缩放按钮，也不会挡住上面的导航蓝框。
- **酷狗的大歌词页有词了**：读的是它播放器手里那段 LRC（它的面板把时间戳丢掉了）；首页/搜索页的标题也不会再被当成歌名。
- **开应用不再自己弹输入法**：站点在页面加载时抢的焦点不算数，点搜索框才升起来。
- **图标换成官方样子**：酷狗是蓝底白环白 K，抖音就是你给的那张。
- 油量那句收短成「油量 412 升，剩余里程 780 公里」。
- 断电暂停、上电续播本来就对所有网页应用生效（除 B 站），酷狗补上播放键与「在放」上报后就一并有了。
- **酷狗的大歌词页终于通**：它的词晚一步才交出来，而歌词原来只在换歌那一下读一次——现在读到为止每趟都读。
  日志里会出现 `lyricProbe: kugou: N lines`，没词时把这一行发我就能定位。
- **输入法再修**：页面里随便点一下也算「要打字」、站点在第一次点击后自己抢焦点，这两条漏的现在都堵上了——只有点在输入框上才升。
- **大歌词页的按钮**：歌词其实早就到手了（日志 `[kugou] its words: 50 lines`），是仪表盘上那个歌词按钮只给了 QQ 音乐和网易云，
  酷狗没按钮。现在三个音乐站点都有，按一下就是全屏歌词。
- **抖音的音量只听它自己的**：它的播放器上有音量条，以前首页卡片那条会每秒把音量改回去。现在抖音归到「播放器自己说了算」
  那一类（和 B 站一样）——首页卡片上不再出现音量条。**但方向盘/手柄上的音量键仍然能调它**：按一下设一次、按住 1.2 秒
  （它自己的播放器重画时会把音量写回去，不按住就听不到），之后撒手——不记、不每秒改回去，所以按完以后抖音的滑条
  还是说了算；下一按从它当前的音量加减 5%。
- **打转向灯时看得到后视镜**：仪表盘上，拨左灯在地图左上角浮出**游戏真实的左后视镜**，拨右灯在控件列顶部浮出右后视镜；
  松手后约 2 秒收起，双闪不显示。它是游戏自己画的镜面（模组把镜面材质垫在页面下面，页面在槽位挖孔透出来），所以是真的镜子。
  **需要重新跑一次安装（写模组 `westplay.scs`）并重启游戏。**
- **后视镜「只露出一角」已修**：上一版打灯时孔、外边框都在，但透出来的是被裁掉一角的镜子。原因是页面量尺寸时量到了被界面缩放
  （`--ui-scale`，这台车 0.78）缩过的那一层，孔只有镜子的 78% 还偏了位。现在槽位与孔都只用页面自己的像素（1280×720，
  与模组里那两个元素同一套数字），任何缩放都不再影响它；平板那种「模型直接显示纹理」的屏幕不会挖孔。
- **后视镜第一次不显示（一个黑块）已修**：镜面是「页面挖孔 + 模组画镜面」两半拼的，程序升级时模组 `westplay.scs` 没有跟着重做，
  孔下面什么都没画。现在模组里带 layout 版本，程序见版本旧就自己重做一次（日志里会有 `layout 2 (the mod's was false)`）。
- **哔哩哔哩也能用音量快捷键**：方向盘/手柄上的音量键现在能调 B 站的声量（和抖音一样：按一下从它当前音量加减 5%，
  按住 1.2 秒防止被它自己的播放器顶回去，然后交给它自己的滑条）。
- **哔哩哔哩倒车压音量修好**：以前挂 R 档声音不降（那条音量通道被「站点自己的音量说了算」关掉了）。现在多了一条
  「座舱自己的安静」：挂 R 档压到 15%、出 R 档还原成它原来的音量，站点自己的滑条依旧说了算。
- **两个新仪表盘小组件**（设置 › 仪表盘里多两个拨杆，默认关）：
  - **相册展示**：开了以后在同一个设置页里「选择图片」，挑的就是**壁纸图库**里的那些（第一张是「跟随壁纸」，不选也有图）；
    首页右列显示这张图，按卡片比例裁满，**图上不写字**。
  - **车辆状态**：最上面「车辆状态」，下面「车身：34%」；挂着挂车时再多一行「挂车：20%」。**不含轮胎磨损**（你的要求），
    字是纯色、深浅色模式各用各的文字色；百分比**向下取整**（4.9% 写 4%，不会写成 5%）。游戏没开时写「等待游戏数据…」。
- **顶部轮播只留两句**：强制休息和油量（含剩余里程）。车速/限速那句和交货倒计时那句按你的要求去掉了。
- **「每个应用启动都弹输入法」的真凶**：不是页面抢焦点，是**上一个网页应用留下的焦点**——换应用时没清，新应用一挂载就把键盘带上来
  （日志里 `[kugou] opened` 和「input method takes the player's keys」在同一毫秒，那时新页面还没加载）。现在换应用、页面重载都会清干净。

- **仪表盘那面后视镜可以关了**（设置 › 显示与性能 › **虚拟后视镜**，默认开）：关掉以后页面不挖孔、不画外框、不显示；
  打开马上恢复。开关跟着页面自己的设置存，换卡车、重装都还在。游戏的 F2 虚拟后视镜仍归游戏自己，WestPlay 不碰游戏配置。
- **有导航点时不再弹「附近推荐」**：那张卡片原来只要「到了」（最后一公里）或刚交付就会弹，现在再看一眼 GPS——
  只要地图上还有导航点就整张不画；交付之后、路线清掉，它自己回来。
- **安装包自带一份 `westplay.scs`**：装完程序旁边就有一份（带镜面元素），新机器不必等程序先做一遍。它是垫底的：
  程序把模组的 layout 升到 3，所以游戏一关就会按**本机**的游戏与已装模组重做一份盖掉它（内容只差 layout 那一行，
  所以不用为这个再重启游戏）。
- **切到原版导航时，那两个虚拟后视镜的框没了**（你说「不用做后视镜了」）：
  - 原因：模组在 GPS 页里加了三个游戏自己的 UI 元素（park + 左右两面镜子，层 99），**不管 WestPlay 开没开，
    游戏都会把它们画出来**，所以页面一变透明、原版导航露出来，两个框就骑在导航上。
  - 现在这三个元素**整个撤掉**（模组 layout 5 → 6，程序下次启动会自动重做一份）；页面上的镜像控件、挖孔，
    以及设置里那一项「虚拟后视镜」也一起删了。
  - 代价：仪表盘上不再有镜面预览（打灯也不再有）；**车上的真镜子、创意工坊那套数字后视镜不受影响**。
- **倒车影像要真实画面：试了，撤回了**（你要的两点：挂 R 触发、整屏、像乘用车那样）：
  - 模组里加了一个铺满屏幕的 `park` 元素，材质是游戏自己的驻车摄像头渲染目标
    `/material/environment/mirror/park_1x1_ui.mat`（和仪表盘后视镜同一族，Ford 那辆车的仪表页也是这么放的），
    模组 layout 因此到 4、再改成 **5**。
  - 两次实机测试的结论：元素、层、坐标、R 档触发、整页让位**全都对**，画面也确实出现了 —— 但出现的是那张材质
    **自带的测试图**（`1x1` / `PARK` 加红绿辅助线）：引擎从来没往这个渲染目标里画过一帧。
  - 又试了游戏自己的「驻车摄像头」（`parking_cams` 键、`g_cam_parking` 开关）：对卡车没用，按下去反而把**镜子**
    也变成 `close` 占位图（那个模式是把摄像头画面塞进镜子的渲染目标，卡车没有摄像头源）。
  - 原因：这套驻车画面是引擎给**乘用车**（ATS 公路旅行那几辆 Ford）准备的，卡车的定义里根本没有这个开关
    —— 26 辆卡车的 `data.sii`、游戏全部 `ui/` 与 `def/vehicle/` 里都没有一处 `parking`。
  - 所以**齿轮菜单回到原来那五种手绘图，默认「两种」**；`live`（游戏画面）那套代码留着不删，等以后插件自己
    渲出一张真图再接上。模组里那个元素也留着，挪到镜子**下面**（打灯挖孔、镜子都不受影响），算给插件留的口子。
  - 镜子变占位图那一下是游戏那个按键干的：**再按一次、或者重启游戏就恢复**。
## 三、这一版的事实

- 游戏插件没动：`westplay.dll` `584,192 B`，与游戏里那份完全相同，**游戏不用重启**；每次重打安装包都把这一版 dll
  重新放进去（这一版静默安装核对过，装出来的就是 `93536599…`）。
- 桌面程序 `D:\WestPlay\westplay.exe`：`24,660,480 B` / `3AC22D501CB61D0FBF87FBAFD93C0D961E6CCEF8336A5DA1DF756F8CB2B100EE`
  （安装包里那一份只差 3 个字节的 PE 头，同一个构建）。安装包 `11,826,217 B` / `05E00019E83E55DD83487384045DF74D69D0B0826602FD508BF9AA184B0DE815`。
- 模组 `westplay.scs` 这一版是 **layout 6**（三个镜面元素都撤掉了）：**先关掉游戏**，WestPlay 跑一次就会重做
  （日志里 `layout 6`）；旧的那几份（layout 3/4/5）不用管，程序自己会盖掉。
- 安装包、两个源码包都在 `D:\West Update`。
