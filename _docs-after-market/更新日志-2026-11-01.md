# WestPlay 2.1.4 更新日志 · 2026-11-01

安装包：`WestPlay_2.1.4_x64-setup.exe`（10,320,508 B）
校验：`7B6A45AE610810A1B8222D39A6D9750798D4ADD8AC5C00193C47000D3FFE3D8F`

## 一、新增功能

1. **性能模式**（设置 › 显示与性能）：一次收起三样最贵的效果——地图的 3D 建筑、毛玻璃、动画；毛玻璃换成适配深色模式的纯色透明底。和「屏幕刷新率」合并到同一个「显示与性能」页里。

2. **中文字库扩容**：打不出的常用字补齐到 **7,735 字、29,867 词条**（原来实际只有 5,410 字，高频音节的字被候选上限截掉了）。

3. **拼音候选每页 8 个**，并去掉了挡住第八个候选的那颗「收起」键（底部键盘的收起键保留）。

4. **车辆信息 app**：左侧车辆名称，右侧车辆状态——卡车的发动机/变速箱/驾驶室/底盘/轮胎五项磨损，接上挂车和接货后显示挂车与货物损伤，全部来自游戏自己的遥测，不估算。

5. **倒车影像**：挂 R 档自动出现——未连接挂车是车尾视角，连接挂车是车顶视角；带随方向盘弯的**红黄绿三色辅助线**和黄色小字「倒车时请注意后方安全」。

6. **倒车时音乐自动压到 15%**，挂出倒挡恢复原音量（四个网页应用、YouTube、Spotify、Apple Music、YouTube Music 都管）。

7. **明暗壁纸**：设置 › 壁纸里可以给浅色、深色模式各指定一张壁纸；和「壁纸轮换」互斥（开一个自动关另一个），两张默认壁纸移出轮换池。

8. **快捷键控制网页应用**：哔哩哔哩、网易云音乐、QQ 音乐、蜻蜓 FM 现在也吃「调低音量 / 播放暂停 / 调高音量」这组热键。

9. **显示优先级**：卡车屏幕页里可选「车机优先 / 平板优先」——车里同时有车机和平板时，决定哪块显示 WestPlay。

10. **地图 App 右上角 2D / 3D 切换**：2D 是从正上方看（还是跟着车、车头朝上），3D 是原来的倾斜驾驶视角。

11. **网易云音乐换成新版网页播放器**（`music.163.com/st/webplayer`），旧版已有的功能都接了过来。

12. **网页页面的拖动条**：站点页面底部与右侧各一条细的圆角滚动条（半透明、悬停变亮）；页面放大后可以拖到被裁掉的部分，站点比自己排得宽时也一样。

13. **页面放大改用 右 Ctrl + 滚轮**：更细腻、无级；左 Ctrl + 滚轮完全还给游戏（换挡）。

14. **QQ 音乐首页：媒体卡片不动，上电还是不续播**：首页的播放条是「打开播放器」的精灵，没有进度、没有声音元素，页面什么都不报——座舱的 `playing` 一直是断电前的「在播」，上电就判成不用发，续播从来没发出去。现在上电**不问页面**：WestPlay 停掉的由 WestPlay 放回去（断电期间自己起的会先被按停）。页面另外读 Windows 自己的媒体状态，控件没有名字时按 class 认，首页播放条的结构会打进日志（下一轮照它修卡片）。

15. **歌停了，卡片还显示在播**：座舱自己按下播放/暂停的那句话（`intent`）从上一版起不再过期——页面没画进度时钟、没有声音元素、系统媒体状态也读不到时，卡片就一直照着那一次按下说。现在它只活 6 秒；页面有自己的声音元素时以元素为准；四个来源都读不到时全部写进日志（`stateProbe`），下一次就能指名道姓。

16. **倒车影像退回第一版****红绿灯读秒**：地图上画出前方最近那盏灯（三灯外壳 + 剩余秒数徽章），灯色和读秒直接读游戏进程内存，跟着车走、贴在蓝色路线上；设置 › 外观 ›「红绿灯显示」可以关掉（关掉后宿主不再读游戏内存）。

17. **QQ 音乐的播放状态跟卡片控件是反的（还是没修干净）**：座舱自己按下播放/暂停时，界面会先把图标翻过去等页面的回答；这句「翻过去的答案」从 §51 起**没有期限**——QQ 音乐首页根本不会再报，图标就一直停在按下的那一刻，页面在播它显示停、页面停了它显示播。现在它只活 2.5 秒，页面的报告一到就立刻交还。

18. **网易云音乐没有卡片 / 控件**：新版播放条上不写歌名（`.words .name` 是空的），页面读不到歌名就整个不报。现在条上没有字时读页面自己的标题（「歌名 - 歌手 - 网易云音乐」），歌名、歌手、控件照旧。

19. **哔哩哔哩滚轮不能上下翻页**：滚轮除了照旧交给 WebView2，现在还会以 `webAppWheel` 告诉页面；页面先给 WebView2 自己的滚轮 90 毫秒，没动就自己滚（光标下最深的可滚容器，没有就整页）。WebView2 把滚轮吞掉时也照样能翻，能滚时不会滚两倍。

20. **首次安装后游戏里还是旧版 `westplay.dll`**：安装时游戏若正开着，旧插件被它占用，宿主就报「占用」不装了。现在被占用时把旧的**改名挪到一边**（Windows 允许改名已加载的 DLL），这一版放进原位，游戏下次启动就是新版；之后再把 `*.old` 清掉。

21. **网易云外部登录（新版页面）窗口不关**：新版登录是点「登录」弹出的窗，顶部条结构也变了，而且 `MUSIC_U` 现在是 HttpOnly（页面读不到 cookie）。现在读不到 cookie 时改看头部条——没有「登录」二字、有头像就算登录。

22. **QQ 音乐的播放状态还是反的（暂停显示在播）**：真因是页面自己的一个**空媒体元素**——QQ 播放器页造了一个没有地址、读不出数据的 `<audio>`，`play()` 一调它就永远不是「暂停」，被当成「正在放歌的那一个」，于是状态永远是在播。现在只有当元素真有东西可播（有地址/流且已读入）才算歌。

23. **网易云音乐不能切歌**：新版播放器的控件是图标字体的文字（`<span class="cmd-icon">prev</span>`），没有 `title`、也不是按钮标签，所以「上一首/下一首」按不到。现在会按「控件自己说的话」找它；再找不到就发播放器自己的 `Ctrl+←/→`（它的播放条上就写着这两个键）。
24. **网易云音乐的切歌（座舱首页卡片上的上一首/下一首）**：新版播放器把这两个键画成 SVG 图标，没有文字也没有 title，按名字根本找不到；但它自己给 Windows 的媒体键注册了「上一首/下一首」两个动作。现在 WestPlay 在页面脚本之前把这些动作记下来，切歌时直接调它自己的——队列是它自己走的。其它站点（QQ 音乐等）照旧按它们自己的按钮。

## 二、修复的问题

1. **部分机器黑屏 / 屏幕只显示游戏画面（一帧都不填）**：原来的 Present 钩子是从系统 `d3d11.dll` 造的临时交换链上取 vtable，玩家机器上往往有三份 `dxgi.dll`（游戏自带、ReShade、系统），钩子可能挂在别人的 detour 上永不触发。现在改为**从游戏 exe 同目录的 `dxgi.dll` 取 vtable**（没有就退回原行为），并在日志里打出钩到哪个模块、进程里有哪几份 `dxgi.dll`，另加「连续 20 秒没有新帧」的告警。

2. **网页应用没有拖动条、放大以后无法拖动**：注入页面的脚本是在页面还没有 `<html>` 的时候就执行的，原来那句 `document.documentElement.append(style)` 抛异常，**把整个页面脚本从这里打断**——样式一次都没装进去；现在改成等页面有 document 了再装（`DOMContentLoaded`）。

3. **网页应用的音量 / 歌词 / 输入框打字一起失效**（同上一条的连带问题）：那个异常把 `webapp.js` 后面的注入全部跳过了，修好注入时机后一并恢复。

4. **页面放大和换挡按键冲突**：放大原来用左 Ctrl + 滚轮，而左 Ctrl + 滚轮正是换挡；现在只认**右 Ctrl**。

5. **拼音候选框右边被「收起」键挡住、一页只有 3~5 个候选**：移除那颗键，候选改成每页 8 个。

6. **常用字打不出来**（「yi」172 个常用字只露 24 个）：候选上限与字池一起放开，字库从 5,410 字扩到 7,735 字。

7. **网页应用的快捷键（播放/暂停、调低/调高音量）不灵**：网易云新版播放器的声音是页面自己造出来、**不放回页面**的媒体元素，音量改的是「查询到的元素」，所以按了没反应；现在页面把「造出来但没放进页面」的媒体也记下并一起调音量。暂停中的站点也算「有东西可放」，按热键能把暂停的站点叫回来。

8. **QQ 音乐用快捷键暂停后，暂停图标要好几秒才变，有时还自己又播起来**：QQ 的按钮名字更新很慢，页面原来拿「名字变没变」判断这一下生效没，判成没生效就再点一次（播放/暂停是开关，等于把暂停点回播放）。现在改看页面自己的媒体元素——按下的瞬间图标就变，也只点一次；断电暂停、上电续播因此不再被自己点回去。

9. **QQ 音乐暂停后图标是反的（而且断电后上电不会自动续播）**：页面把「在不在播」读的是站点自己的按钮名字，而那名字要好几秒才更新——刚按完暂停，页面还在报「在播」，于是图标反、上电也以为已经在播。现在车厢按下的那一下说了算，站点改口前以它为准。

10. **另一台设备上检测不到游戏**：那台机器游戏目录里的 `westplay.dll` 还是旧版——插件日志里是 `24/24 channels`（这一版是 33），而桥接是按版本命名的（`Local\WestPlay.Bridge.v26`），旧插件开的另一个名字，两边永远碰不上，主机读到的 pid 是 0，于是安静地显示「未运行」。现在 WestPlay 会在启动时、游戏关闭时、以及一直没看到游戏时每 30 秒，把 exe 旁的 dll 跟游戏 `plugins` 里那个比一比，不同就自动装进去（游戏开着装不上时，日志会写清原因）。插件加载行也带上了 `bridge v26`，以后两边的版本一眼就能对上。

11. **QQ 音乐断电暂停后，上电不自动续播**：页面报的「在不在播」在断电暂停后仍然是「在播」——它读的「时钟在动」其实是推算出来的位置，永远在动；站点按钮名字又滞后。上电时于是判成「它已经在播了」，什么都不发。现在改为看真正的时钟跳动（页面画过进度就以时钟为准），并在说完「plays on」1.6 秒后再核一次，没回来就再发一次。

12. **伴侣页会直接说「游戏里的 WestPlay 插件是旧版本」**（红字，带做法），不用再翻日志猜。

13. **倒车影像退回第一版**：撤回了中间试过的「地图正上方俯视」方案，回到手绘倒车影像（车尾 / 车顶两套 + 三色辅助线），也就是现在这一版。
